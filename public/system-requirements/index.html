Shift At Midnight system requirements

Minimum is a GTX 1050 Ti, an Intel Core i5-10400F and 8 GB of RAM, and the install is 3 GB. Both tiers below are copied field for field from the Steam store listing, alongside what the Xbox listing showed on 12 August 2026 and what Valve’s Steam Deck compatibility report returns.

Steam data re-read 10 October 2026 (store data and Valve’s compatibility report) · Xbox rows last read 12 August 2026, not re-checked · latest patch: 1 September 2026

The short answer

This is a small game and the requirements say so. Minimum: Windows 10/11 64-bit, an i5-10400F, 8 GB RAM, a GTX 1050 Ti, DirectX 11 and 3 GB of free space. A broadband connection is listed on both tiers, because the co-op is online only. The Steam figures on this page were re-read from Steam’s store data on 10 October 2026 and match the 12 August 2026 reading. The Xbox rows are from the Xbox listing as read on 12 August 2026 and were not re-checked.

Recommended specification, as Steam lists it

ProcessorIntel Core i5-10400 / AMD Ryzen 7 5800X or Equivalent
Memory16 GB RAM
GraphicsNVIDIA GeForce GTX 1660 Ti (6GB) or Equivalent
DirectXVersion 12
NetworkBroadband Internet connection
Storage3 GB available space

Source: the Steam store listing; Steam store data read 10 October 2026 (unchanged from 12 August 2026). Both tiers list the same 3 GB install size.

The processor row that looks like a mistake

Read the two processor lines next to each other and the recommended tier looks like a downgrade: minimum asks for an i5-10400F, recommended asks for an i5-10400. We have reproduced both rows exactly as the store page prints them rather than tidying one to match the other. We do not know whether that is a typo on the listing or deliberate, and there is no second source for either row — the store page is the only place these specs are published.

The usable reading is that a tenth-generation i5 clears both tiers, and the real distance between minimum and recommended sits elsewhere: the graphics card, the RAM, and DirectX 11 against 12.

Steam Deck: what Valve’s compatibility report returns

Valve’s compatibility report for the game, read on 10 October 2026, returns category 2 for Steam Deck, SteamOS and Steam Machine alike. Its test list for Steam Deck includes “Default controller config not fully functional”, “Controller glyphs do not match the device” and “Text input does not automatically invoke the keyboard”. We print the number as returned and do not attach a badge name to it. The full test-by-test table is on platforms.

What we could not read

ProtonDB, the other place people check, needs JavaScript to render its reports and we could not read it; it was not re-checked on 10 October 2026.

Valve’s report lists a controller-configuration warning for this game; read the full list above before buying for a Deck. There is also an open Steam discussion thread titled “Steam deck - i press play and nothing happens”. We have no verified fix for that — what we can and cannot say about it is on troubleshooting.

What the Xbox listing showed on 12 August 2026 (not re-checked on 10 October 2026)

Price$9.99 — included with PC Game Pass and Xbox Game Pass Ultimate
Co-opOnline co-op 2–3 players; Xbox cross-platform co-op
Display4K Ultra HD; Optimized for Xbox Series X|S
SavesXbox cloud saves
OwnershipXbox Play Anywhere
HandheldHandheld compatible
StreamingCloud playable, with Game Pass Ultimate

Two of those rows change the answer to “can I run it”. Cloud playable means a Game Pass Ultimate subscriber can start it on hardware that meets none of the specs above, because the game is not running on their machine. On the Steam side, the developer’s 20 August 2026 announcement says “Added cloud saves for Steam”, and Steam’s store data listed a Steam Cloud category when we read it on 10 October 2026 — see the next section.

One row is worth flagging rather than smoothing over: the Xbox listing recorded online co-op as 2–3 players when we read it on 12 August 2026, while the 23 July 2026 patch made the lobby cap selectable up to six on Steam. We have found no official statement about whether that six-player option exists on Xbox, so we are not going to assume it does. See multiplayer for what the developer actually said about lobby size.

Saves: Steam Cloud is listed

Steam’s store data lists ten categories on 10 October 2026: Single-player, Multi-player, Co-op, Online Co-op, Steam Achievements, Adjustable Text Size, Custom Volume Controls, Stereo Sound, Steam Cloud and Family Sharing. Steam Cloud is on that list. The developer’s 20 August 2026 announcement, “15 CUSTOMERS + BUG FIXES”, says “Added cloud saves for Steam”. Steam Cloud was not on the list when we read it on 12 August 2026; the store data carries no history, so we cannot say on which day the category first appeared.

We have not verified how Steam Cloud behaves for this game. We are not going to tell you which folder to back up, because we could not verify a save path — that is in the last section, with the reason.

Controller, accessibility and two different age ratings

  • Controller: Steam’s store data for the game (10 October 2026) lists no controller-support category and the separate controller support field is absent. We have found no official note on which inputs are or are not mapped.
  • Accessibility: Steam records Adjustable Text Size and Custom Volume Controls as features, and lists audio as Stereo Sound. There is no surround or spatial-audio flag on the listing, which is worth knowing in a game where sound direction is a survival tool — see survival.
  • Languages: nine on Steam, listed in full on release date.
  • Family Sharing: listed as supported on Steam.
  • Age rating: the two storefronts present this very differently. Steam’s listing carries a required age of 0; its content descriptor note reads “Plenty of gore and blood present.” (read 10 October 2026). The Xbox store listed it as MATURE 17+ for Violence, Blood and Gore, and Language when read on 12 August 2026 (not re-checked). Same game, two labels that look nothing alike.

What this page cannot tell you, and why

Four things people ask that are deliberately missing above:

  • Frame rates on specific hardware. No benchmark we could check has been published. A spec sheet is not a benchmark and we are not going to convert one into the other.
  • Save file locations, config file paths, and the in-game graphics options list. The usual reference for this is PC Gaming Wiki. Both URL variants we tried returned HTTP 403 on 12 August 2026, so there is nothing here we could verify and nothing to copy.
  • Xbox install size. The Xbox listing did not show one when we read it. The 3 GB above is the Steam number and we are not assuming it transfers.
  • Linux and Proton behaviour. ProtonDB requires JavaScript to render and we could not read it. Valve’s own compatibility report (10 October 2026) is the only compatibility signal we have.

If any of those become verifiable, they get added here with a date and a source, the way everything else on this page is.
