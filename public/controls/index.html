Shift At Midnight controls

Steam lists no controller support for Shift At Midnight. Steam's store data for the game (read 10 October 2026) lists no controller-support category and the separate controller support field is absent. That means none is declared; it does not say the game rejects a gamepad. The Xbox Series X|S version is a separate build and we have not checked its controls.

The direct answer

Steam's store data lists ten categories on 10 October 2026 and none is a controller category; the controller support field is not returned. Valve's own Deck report flags “Default controller config not fully functional”. Beyond that we have found no official statement about gamepads.

Why this feels wrong for an Xbox game

The developer's launch post names Xbox and Game Pass alongside Steam (22 July 2026; see platforms). The Xbox Series X|S version is a separate build; we have not checked its controls.

This is also why the question keeps coming up in the game's own Steam discussions, where a thread titled "Is controller support planned?" sits alongside a separate "Please add gamepad support!" post. Neither has a developer reply confirming a change, so treat controller support as absent until Kwalee or Bun Muen says otherwise — not as something quietly being worked on.

What actually works: keyboard and mouse

The verified interaction model is mouse-driven. Serving a customer means reading an ID at a terminal, cross-checking details in the N.E.T. database, and making a judgement call — all screen-and-cursor tasks that do not map cleanly onto a gamepad's face buttons and sticks, which is the most plausible reason a solo developer skipped controller support rather than shipping a broken one.

One binding is confirmed from in-game material this wiki has already verified: interacting with the wind-up music box that triggers the Marionette encounter is done by holding E to rewind it — see the Jack-in-the-Box page. Beyond that specific, confirmed key, we have not found an official, complete keybind list published by the developer, and we are not going to invent one. Standard first-person conventions (WASD movement, mouse-look, mouse-click to interact) are a safe general assumption for a game in this genre, but treat anything more specific than the E-to-rewind binding as unconfirmed until we can source it.

If you were hoping to remap keys

We found no evidence of an in-game key-rebinding menu in any source we checked, official or otherwise. If remapping matters to you, the safer route on PC is a system-level or Steam-level remap (Steam's own controller/keyboard configurator, or Windows key-remapping software) rather than assuming the game exposes one itself. We have not tested this ourselves, so we're not calling it confirmed either way — just the more realistic option.

Steam Deck and controller-only handhelds

Valve's own Deck report (10 October 2026) flags “Default controller config not fully functional” for Steam Deck, SteamOS and Steam Machine. The system requirements page covers the report in detail.

Can you force a controller to work anyway?

People do get gamepads working on PC shooters with no native support through Steam's generic gamepad-to-keyboard/mouse translation (via a Steam Input desktop configuration) or third-party tools like a community controller layout. We have not verified a working configuration for Shift At Midnight specifically. If you find one that works reliably, the most useful place to report it is the game's own Steam discussions, not a third-party trainer site.

What the most recent patch changed

Four patches have shipped since launch (23 July, 29 July, 20 August and 1 September 2026; all official Steam announcements checked 10 October 2026). None of their changelogs mentions controller support or key bindings; see updates. If this is the first page of the wiki you've landed on, the reading order guide sequences everything else from here.

Quick answers

Does Shift At Midnight have full controller support?

None is listed on Steam. The Steam store data lists no controller category (10 October 2026). The Xbox Series X|S version is a separate build and we have not checked its controls.

Can I use a controller on the Steam version?

Not officially: the Steam store data lists no controller category (10 October 2026). Community workarounds using Steam's generic input translation may exist, but we have not verified one.

Is it playable on Steam Deck without a controller working properly?

Valve's compatibility report (read 10 October 2026) returns category 2 for Steam Deck and lists “Default controller config not fully functional”. Full detail on system requirements.
